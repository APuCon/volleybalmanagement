# Volleybal Tracker v5

Best-of-five: maximaal vijf sets, wedstrijd stopt zodra een team drie sets heeft gewonnen. Set 5 gaat tot 15; overige sets tot 25, altijd twee punten verschil.

Inclusief puntenhistorie, maximaal vier reserves en vier afwezigen per set, cumulatieve sets- en wedstrijdtellingen, offline opslag en Azure synchronisatie.

Azure workflow: `app_location: /`, `api_location: api`, `output_location: dist`.
