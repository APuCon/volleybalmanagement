# Volleybal Tracker

Er worden altijd vier sets gespeeld. Alleen bij 2-2 na vier sets volgt een beslissende vijfde set. Set 5 gaat tot 15 punten; sets 1 tot en met 4 tot 25 punten, steeds met twee punten verschil.

Inclusief PowerPoint-gebaseerde rotaties, positienummer en rol in ieder spelersvak, puntenhistorie, maximaal vier reserves en vier afwezigen per set, cumulatieve sets- en wedstrijdtellingen, tussentijds een nieuwe wedstrijd starten, offline opslag en Azure-synchronisatie.

Azure workflow: `app_location: /`, `api_location: api`, `output_location: dist`.
